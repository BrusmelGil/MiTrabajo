# 🎬 Proyecto de Clasificación de Géneros Literarios

Este proyecto tiene como objetivo **organizar textos según su género literario**.  
Para ello, he creado una estructura sencilla pero clara que facilita el manejo y clasificación del contenido.

---


## 📁 Estructura del Proyecto

La carpeta principal contiene **tres subcarpetas**, cada una dedicada a un género distinto:

📂 TRABAJOREPO
├── 📁 comedia
│ └── 📝 comedia.txt
├── 📁 romance
│ └── 📝 libro.txt
└── 📁 terror
└── 📝 miedo.txt

----

## ✍️ Descripción de cada género

### 💞 Romance
Historias que exploran el amor, la pasión y las emociones entre los personajes.  
Aquí se recopilan textos cargados de sentimientos y relaciones personales.

### 😂 Comedia
Relatos y situaciones cómicas diseñadas para sacar una sonrisa.  
El archivo dentro de esta carpeta contendrá ideas, guiones o textos con tono humorístico.

### 👻 Terror
Textos que buscan provocar miedo, suspenso o inquietud.  
En esta carpeta se incluirán fragmentos oscuros, relatos de horror o cualquier contenido escalofriante.

---

## 🌟 Objetivo del Proyecto

La finalidad de esta organización es **mantener una estructura limpia y coherente** para trabajar con distintos géneros literarios.  
Esto facilitará tanto la **edición** como la **ampliación futura** del contenido (por ejemplo, agregando más géneros o subdivisiones).
