# 🎬 Proyecto de Clasificación de Géneros Literarios

Este proyecto tiene como objetivo **organizar textos según su género literario** y sirve como entorno de trabajo para la **colaboración con compañeros** mediante el uso de Git y GitHub.

---

## 🛠️ Colaboración y Repositorios Vinculados

Como parte de la práctica de Git, este repositorio ha sido actualizado para **albergar y gestionar** la colaboración con otros cuatro repositorios de compañeros.

**Se han clonado, modificado, guardado y subido los cambios a los siguientes repositorios externos** (trabajando directamente en la rama `main`):

| Repositorio Clonado | URL Base | Objetivo |
| :--- | :--- | :--- |
| `pelis-series-repo` | `github.com/Alba-34/...` | Clasificación de películas y series. |
| `bbdd_series` | `github.com/Aida-qar82447/...` | Base de datos de series. |
| `Practica-grupal-14-10` | *(URL de este repositorio)* | Tarea grupal específica. |
| `musica-repo-colaborativo` | `github.com/Morgothsdragon/...` | Clasificación de géneros musicales. |

**Finalidad:** Cada uno de los compañeros puede ahora ejecutar un **`git pull origin main`** en su repositorio para obtener y sincronizar las modificaciones que he agregado, garantizando que todos tengamos la misma versión actualizada del código.

## ✍️ Descripción de cada género

### 💞 Romance
Historias que exploran el amor, la pasión y las emociones entre los personajes. Aquí se recopilan textos cargados de sentimientos y relaciones personales.

### 😂 Comedia
Relatos y situaciones cómicas diseñadas para sacar una sonrisa. El archivo dentro de esta carpeta contendrá ideas, guiones o textos con tono humorístico.

### 👻 Terror
Textos que buscan provocar miedo, suspenso o inquietud. En esta carpeta se incluirán fragmentos oscuros, relatos de horror o cualquier contenido escalofriante.
